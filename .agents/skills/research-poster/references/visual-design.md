# Conference research-poster design system

## Narrative beats
Title → 8-second takeaway → Problem → Why it matters → Method (dominant figure) → Evidence (2–3 visualized numbers) → Limitations → Citation/QR. Use one concept per section, large labels and one intentional focal point.

## Recommended format
- Default **48×36 in, landscape**, print PDF (3:4 aspect), configurable when venue specifies A0/A1 or portrait.
- Safe margin 0.9–1.2 in; gutter 0.4–0.65 in.
- Hybrid 3-column grid: **~25% context, 45% method, 25% evidence**, remaining gutters.
- Visual hierarchy: title ~95–120 pt; key takeaway 40–55 pt; section 28–36 pt; core content 20–28 pt; footnote 14–18 pt at full poster size.
- Body paragraphs: 30–45 words max; switch to labeled diagrams, captions and cards.
- Strong white/near-white body; dark headline panel; max 2 accent hues plus semantic warning hue.
- Recommended sample palette: midnight `#112B3C`, ink `#173044`, teal `#0F968E`, coral `#FF815C`, paper `#F6F8F7`.
- Reserve at least 20–30% empty area; avoid decorative outlines around every box.
- Ensure at least WCAG AA contrast when practical; never encode meaning by color alone.

## Layout alternatives
1. **Traditional tri-column**: dense empirical paper with multiple methods.
2. **Headline-first / BetterPoster**: one surprising, source-backed message; few figures.
3. **Hybrid research narrative**: central technical figure with supporting context and evidence; preferred for ML architecture papers.
4. **Methods atlas**: multiple equally important algorithms/ablation plots; use only when a single hero graphic would mislead.

## Accessibility
Provide plain-language title, meaningful SVG title/desc and figure captions. Avoid <20pt key labels in default print size. Validate printed scale and small screen as independent experiences; web gallery thumbnail is not a substitute for a print legibility review.

## Visual QA checklist
At 100% size: align margins and grids; remove clipped lines; resolve orphaned words; check QR can scan; verify units; test figure contrast without color; compare poster headings against actual main finding.
